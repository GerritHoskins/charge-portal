# WP-03 — Synthetic catalogue data and images for the stand-in

**Depends on:** WP-02.

## Goal

About 40 synthetic products (charging cards, wallboxes, cables, adapters) in two categories,
in the raw Store-API shape from WP-02, plus placeholder product images.

## Read

- `shared/contracts/catalog.ts` (only the raw schemas, `storeApi*`)
- `legacy/data.mjs` (first 10 lines, for style)

## Steps (tests first)

1. Create `tests/unit/legacy-catalog.test.ts` that imports the new data module and asserts:
   - every product parses with `storeApiProductSchema`;
   - ids and `seoPathInfo` values are unique;
   - every image file referenced by `cover.media.url` exists on disk;
   - there are two categories and each has at least 15 products.
   (`legacy/*.mjs` has no type declarations; use `// @ts-expect-error plain .mjs module`
   on the import like `tests/unit/migration-routes.test.ts` does.)
2. Run it → fails.
3. Create `legacy/catalog.mjs`:
   - `categories` (`wallboxes`, `accessories`) and `products` generated by a small
     deterministic function (no `Math.random`; derive values from the index) so data is
     stable between runs.
   - Names are invented and generic ("Wallbox Home 11", "Ladekabel Typ 2, 5 m"). No brand names.
   - Prices as euro floats (Store API style), e.g. 24.90 to 1299.00.
   - `seoPathInfo` like `wallbox-home-11`.
4. Images: create `public/shop/` with one generated placeholder per product in three widths
   (400, 800, 1600 px). Write a small script `scripts/shop-images.mjs` that generates simple SVG
   files (product name and a coloured shape); commit-ready SVG is enough. **WP-20 needs raster
   images to show image optimization**: if `sharp` is already present in `node_modules`
   (it often is, via other packages; check `node -e "require('sharp')"`), let the script also
   write JPEGs; otherwise record in Open questions that raster images need a human decision.
   Image URLs in the data: `/shop/<slug>-1600.jpg` (or `.svg` if no raster).
   The naive pages (WP-09/11) deliberately use the largest size.

## Files you may change

`legacy/catalog.mjs` (new), `scripts/shop-images.mjs` (new), `public/shop/**` (new),
`tests/unit/legacy-catalog.test.ts` (new).

## Done when

The new test passes, `npm run lint` passes. Progress log notes image format (SVG or JPEG) and
total size of `public/shop/`.
