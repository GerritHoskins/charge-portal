## Write `docs/adr/0007-public-shop-and-budgets.md`

**Status:** proposed (becomes accepted in WP-27).

Cover, briefly and concretely:

1. **Why a public area exists in a portal demo:** public SSR pages expose problems the
   logged-in portal hides (cacheable HTML, image-driven LCP, hydration cost, SEO).
2. **Data source:** synthetic catalogue in a subset of the Shopware Store API shape behind the
   existing contract pattern (WP-02/04/06); not a Shopware integration; the `sw-access-key`
   is synthetic.
3. **Public API allowlist** (WP-05): exact paths, why prefix-with-slash, what stays guarded.
4. **Separate shop layout** (WP-07): no session lookup, no CSRF token, no user-specific HTML
   on public pages, and why that is a precondition for caching (WP-22).
5. **Inventory status `nuxt-native`** (WP-01) and why it is excluded from migration progress.
6. **Per-route budget** (WP-13): why the total-JS budget was misleading, how the per-route
   number is measured, the current numbers (copy from the Measurements table), and that shop
   budgets are provisional until the optimizations.
7. **Consequences:** what got more complex (two layouts, two budget mechanisms), what is not
   covered (no server cart, no CDN, `legacy-php/` not updated).
8. **User and business value**, without invented figures.

Also add the ADR link to the list of decision records in `README.md` (one line, the
"Decision records:" sentence). No other README changes in this WP.
